# Minervini Korea Era-Leader VCP Research

Reproducible Korean-equity backtest research for an Era-Leader / Early-Trend / VCP breakout strategy.

Data source: FinanceData/marcap (KRX daily OHLCV, point-in-time rows including delisted history where present).
Research window: primarily 2015 onward because the open-source validation notes stronger reliability from 2015.

This directory is generated for the user's Korean equity strategy research. Signals are evaluated on day D and trades are executed no earlier than D+1 open. No live trading is performed.
